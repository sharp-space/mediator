# SMD006: Generic handler is not discovered

| | |
| --- | --- |
| Severity | Warning |
| Category | Sharp.Mediator |

## Message

> Handler '{0}' is generic, so neither generated code nor AddHandlers can register it. Make it abstract and derive a non-generic handler for each message, for example 'sealed class IntHandler : {0}<int>;'.

## Cause

Generated code and `AddHandlers` register concrete, closed handler types. An open generic handler class matches no specific message type, so it is never discovered and answers no call.

## How to fix

Make the generic handler abstract and derive a non-generic handler for each message.

```csharp
// Flagged: generic, so not discovered.
public sealed class GenericPingHandler<T> : IRequestHandler<Ping<T>, T> { /* ... */ }

// Fixed: abstract base plus a non-generic handler per message.
public abstract class GenericPingHandler<T> : IRequestHandler<Ping<T>, T> { /* ... */ }
public sealed class IntPingHandler : GenericPingHandler<int>;
```

## Suppression

SMD006 is a warning. Suppress it only when the consequence above is what you want.

```csharp
#pragma warning disable SMD006
// ...
#pragma warning restore SMD006
```

```ini
# .editorconfig
dotnet_diagnostic.SMD006.severity = none
```
