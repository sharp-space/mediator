# SMD010: Open-generic middleware cannot be closed at build time

| | |
| --- | --- |
| Severity | Warning |
| Category | Sharp.Mediator |

## Message

> Open-generic middleware '{0}' is private, protected, or file-local, or nested in such a type, so generated code cannot reference it. It is closed via reflection at startup under the JIT and fails at startup under NativeAOT; make it, and any type it is nested in, internal or public.

## Cause

Open-generic middleware is closed over each message at build time by generated code, which cannot name a `private`, `protected`, or `file`-local middleware, or one nested in such a type. `private protected` counts as `protected` here. Under the JIT the middleware is then closed by reflection at startup, which is slower. Under NativeAOT that fallback is unavailable and startup fails.

The analyzer reports this only for middleware declared in the compilation. Middleware another assembly declares is closed where generated code can name it, and left to that assembly where it cannot.

## How to fix

Make the middleware, and any type it is nested in, `internal` or `public`. Make it `public` when other assemblies declare handlers it should apply to, so their generators can close it too.

```csharp
public static class Pipeline
{
    // Flagged
    private sealed class LoggingMiddleware<TMessage> : IMiddleware<TMessage> where TMessage : IMessage { /* ... */ }

    // Fixed
    internal sealed class LoggingMiddleware<TMessage> : IMiddleware<TMessage> where TMessage : IMessage { /* ... */ }
}
```

## Suppression

SMD010 is a warning. Suppress it only when the consequence above is what you want.

```csharp
#pragma warning disable SMD010
// ...
#pragma warning restore SMD010
```

```ini
# .editorconfig
dotnet_diagnostic.SMD010.severity = none
```
