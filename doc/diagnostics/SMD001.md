# SMD001: Request type implements multiple response types

| | |
| --- | --- |
| Severity | Error |
| Category | Sharp.Mediator |

## Message

> Request type '{0}' implements multiple IRequest<TResponse> response types. A request type must have exactly one response type.

## Cause

A request is dispatched to one handler that returns one response type. A type that implements `IRequest<A>` and `IRequest<B>` has no single response type to dispatch to.

## How to fix

Keep exactly one `IRequest<TResponse>` per request type. Split the request in two if you need both responses.

```csharp
// Flagged
public sealed record Query : IRequest<int>, IRequest<string>;

// Fixed
public sealed record QueryCount : IRequest<int>;
public sealed record QueryName : IRequest<string>;
```

## Suppression

This is a build error, so suppressing it only hides the message: the code it points at is not supported. Fix the code instead.
