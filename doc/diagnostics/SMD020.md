# SMD020: Language version is too old for the generated code

| | |
| --- | --- |
| Severity | Error |
| Category | Sharp.Mediator |

## Message

> Sharp.Mediator generates code that needs C# 9 or later, and this project compiles C# {0}, so nothing was generated for it. Set LangVersion to 9 or later.

## Cause

The source generator writes the registrations, routes, and middleware closings that `AddMediator` reads into a file that
runs a module initializer, which needs C# 9, and opens with `#nullable`, which needs C# 8. A project that sets
`LangVersion` below 9 could not compile that file, so the generator writes nothing for it and reports this error instead.

## How to fix

Remove the `LangVersion` setting, so the project compiles the version its target framework defaults to, or set it to 9
or later:

```xml
<PropertyGroup>
    <LangVersion>9</LangVersion>
</PropertyGroup>
```

Statically typed calls reach the mediator through generated interceptors from C# 11 on. With C# 9 or 10 they go through
the mediator's interface instead.

## Suppression

Do not suppress SMD020. Without generated code, `AddMediator` finds no registrations from this project, and the
application fails when it starts or when it first dispatches one of its messages.
