# SMD007: Handler is not accessible from generated code

| | |
| --- | --- |
| Severity | Warning |
| Category | Sharp.Mediator |

## Message

> Handler '{0}' is private, protected, or file-local, or nested in such a type, so AddHandlers cannot register it. Make it, and any type it is nested in, internal or public, or register it explicitly with AddHandler.

## Cause

`AddHandlers` registers the handlers found by the generator, which cannot name a `private`, `protected`, or `file`-local handler, or one nested in such a type. `private protected` counts as `protected` here. That handler is not registered, so its messages are unanswered.

## How to fix

Make the handler, and any type it is nested in, `internal` or `public`, or register it explicitly with `AddHandler`.

```csharp
// Flagged
file sealed class PingHandler : IRequestHandler<Ping, string> { /* ... */ }

// Fixed
internal sealed class PingHandler : IRequestHandler<Ping, string> { /* ... */ }
```

## Suppression

SMD007 is a warning. Suppress it only when the consequence above is what you want.

```csharp
#pragma warning disable SMD007
// ...
#pragma warning restore SMD007
```

```ini
# .editorconfig
dotnet_diagnostic.SMD007.severity = none
```
