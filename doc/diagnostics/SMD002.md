# SMD002: Request type implements both IRequest and IRequest<TResponse>

| | |
| --- | --- |
| Severity | Error |
| Category | Sharp.Mediator |

## Message

> Request type '{0}' implements both IRequest and IRequest<TResponse>. A request type must implement exactly one of them.

## Cause

`IRequest` is a request without a response and `IRequest<TResponse>` is one with a response. A type cannot be dispatched as both.

## How to fix

Implement `IRequest` or `IRequest<TResponse>`, not both.

```csharp
// Flagged
public sealed record Save : IRequest, IRequest<int>;

// Fixed
public sealed record Save : IRequest<int>;
```

## Suppression

This is a build error, so suppressing it only hides the message: the code it points at is not supported. Fix the code instead.
