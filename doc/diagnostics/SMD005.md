# SMD005: Request or stream has multiple handlers

| | |
| --- | --- |
| Severity | Error |
| Category | Sharp.Mediator |

## Message

> Handler service '{0}' has multiple implementations: {1}. Requests and streams require exactly one handler.

## Cause

A request or stream request is answered by exactly one handler. Two or more handler types are declared for the same handler service in the compilation (unlike events, which may have many handlers). The message lists the implementations that were found.

## How to fix

Keep one handler per request or stream request type. Remove the others, or make them handle a different message.

```csharp
// Flagged: two handlers for the same request.
public sealed class PingHandler : IRequestHandler<Ping, int> { /* ... */ }
public sealed class FastPingHandler : IRequestHandler<Ping, int> { /* ... */ }

// Fixed
public sealed class PingHandler : IRequestHandler<Ping, int> { /* ... */ }
```

## Suppression

This is a build error, so suppressing it only hides the message: the code it points at is not supported. Fix the code instead.
