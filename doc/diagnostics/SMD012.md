# SMD012: Closed middleware can never run

| | |
| --- | --- |
| Severity | Warning |
| Category | Sharp.Mediator |

## Message

> Middleware '{0}' implements '{1}', but '{2}' does not dispatch through that pipeline, so it never runs. Void requests and events use IMiddleware<TMessage>, requests with a response use IMiddleware<TMessage, TResponse>, and stream requests use IStreamMiddleware<TRequest, TResponse>.

## Cause

Each kind of message dispatches through one middleware pipeline, and a closed middleware registered for a different pipeline is never invoked.

## How to fix

Implement the middleware interface that matches the message:

| Message | Middleware interface |
| --- | --- |
| `IRequest`, `IEvent` | `IMiddleware<TMessage>` |
| `IRequest<TResponse>` | `IMiddleware<TMessage, TResponse>` |
| `IStreamRequest<TResponse>` | `IStreamMiddleware<TRequest, TResponse>` |

```csharp
// Flagged: Ping has a response, so IMiddleware<Ping> never runs for it.
services.AddMediator(x => x.AddMiddleware<PingLogging>());   // PingLogging : IMiddleware<Ping>

// Fixed
services.AddMediator(x => x.AddMiddleware<PingLogging>());   // PingLogging : IMiddleware<Ping, string>
```

## Suppression

SMD012 is a warning. Suppress it only when the consequence above is what you want.

```csharp
#pragma warning disable SMD012
// ...
#pragma warning restore SMD012
```

```ini
# .editorconfig
dotnet_diagnostic.SMD012.severity = none
```
