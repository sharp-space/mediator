# SMD004: Stream request type implements multiple response types

| | |
| --- | --- |
| Severity | Error |
| Category | Sharp.Mediator |

## Message

> Stream request type '{0}' implements multiple IStreamRequest<TResponse> response types. A stream request type must have exactly one response type.

## Cause

A stream request is dispatched to one stream handler that yields one item type. A type that implements `IStreamRequest<A>` and `IStreamRequest<B>` has no single item type.

## How to fix

Keep exactly one `IStreamRequest<TResponse>` per stream request type.

```csharp
// Flagged
public sealed record Tail : IStreamRequest<string>, IStreamRequest<int>;

// Fixed
public sealed record Tail : IStreamRequest<string>;
```

## Suppression

This is a build error, so suppressing it only hides the message: the code it points at is not supported. Fix the code instead.
