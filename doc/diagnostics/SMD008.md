# SMD008: Request or stream handler is declared for an interface

| | |
| --- | --- |
| Severity | Error |
| Category | Sharp.Mediator |

## Message

> Handler '{0}' handles interface '{1}', but a request is dispatched to the handler of its runtime type or of one of its base classes, never of an interface, so this handler can never run. Declare it for a class or struct instead.

## Cause

A request is dispatched to the handler of its runtime type or one of its base classes. Its runtime type is never an interface, so a handler declared for an interface is never reached.

## How to fix

Declare the handler for a class or struct request type.

```csharp
// Flagged
public sealed class Handler : IRequestHandler<IPing, string> { /* ... */ }

// Fixed
public sealed class Handler : IRequestHandler<Ping, string> { /* ... */ }
```

## Suppression

This is a build error, so suppressing it only hides the message: the code it points at is not supported. Fix the code instead.
