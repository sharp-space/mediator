# SMD011: Open-generic middleware shape is not supported

| | |
| --- | --- |
| Severity | Warning |
| Category | Sharp.Mediator |

## Message

> Open-generic middleware '{0}' must declare exactly the middleware interface's generic parameters in the same order and cannot be nested in a generic containing type. Register the required closed middleware types explicitly instead.

## Cause

Build-time closure only handles a mirror-shaped open generic: one that declares exactly the middleware interface's generic parameters in the same order, and is not nested inside a generic type. Other shapes are not closed, so the middleware does not run for the messages you expect.

## How to fix

Change the middleware to the mirror shape, or register the required closed middleware types explicitly.

```csharp
// Flagged: parameters reordered relative to IMiddleware<TMessage, TResponse>.
public sealed class CacheMiddleware<TResponse, TMessage> : IMiddleware<TMessage, TResponse>
    where TMessage : IMessage<TResponse> { /* ... */ }

// Fixed: same parameters, same order.
public sealed class CacheMiddleware<TMessage, TResponse> : IMiddleware<TMessage, TResponse>
    where TMessage : IMessage<TResponse> { /* ... */ }

// Or register a closed type explicitly.
services.AddMediator(x => x.AddMiddleware<CacheMiddleware<GetUser, User>>());
```

## Suppression

SMD011 is a warning. Suppress it only when the consequence above is what you want.

```csharp
#pragma warning disable SMD011
// ...
#pragma warning restore SMD011
```

```ini
# .editorconfig
dotnet_diagnostic.SMD011.severity = none
```
